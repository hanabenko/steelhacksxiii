# PennDOT AV certificate-holder information

Official source: <https://www.pa.gov/agencies/penndot/research-planning-and-innovation/automated-vehicle/certificate-holders>. This is useful context on certificated HAV testers and stated Pennsylvania operating locations, including Pittsburgh. It is not trajectory, map, telemetry, or behavior data.

No official structured CSV, JSON, or GeoJSON download endpoint was located. To avoid scraping a public HTML registry, this pipeline records it as a reference only and downloads nothing. Add an artifact only if PennDOT later publishes an explicit structured source.
