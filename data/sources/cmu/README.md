# CMU scenario database project

Official project page: <https://ppms.cit.cmu.edu/projects/detail/275>. CMU's Traffic21 project #275 describes a Pittsburgh scenario-based AV database and lists public reports and publications. The project mentions lidar, cameras, radar, GPS, IMU, vehicle controls, and planned smart-city context.

The public record does not provide a downloadable scenario archive or a dataset license. This source is marked restricted. Do not crawl `traffic-net.org` or attempt access to CMU-restricted systems. For availability and terms, contact the listed PI, Ding Zhao: `dingzhao@cmu.edu`.
